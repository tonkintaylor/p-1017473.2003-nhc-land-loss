# Meeting transcripts

The raw Teams transcripts (`.vtt`) of project meetings, kept so that what the
register, the status files and the context notes say can be checked against
what was actually said.

Name each file by meeting date and title, as `YYYY-MM-DD-short-title.vtt`, for
example `2026-09-25-call-with-perrie-gilbert.vtt`. Drop in the file Teams
exports rather than a copy retyped from it.

A transcript is the source, not the record. What came out of a meeting belongs
in the places the `recording-project-context` skill sets out -- tasks,
limitations, improvements and questions in `.agents/context/register.json`,
refinements in `project-objectives.md` and `project-scope.md`, and progress in
each submodule's `status.md` -- with the register's `Source` column naming the
meeting it came from.

Transcripts are verbatim, including side conversation. Trim personal remarks
before committing one; the repository is shared.
