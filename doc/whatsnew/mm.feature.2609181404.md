Added `tdrive_sync.get_source_mat(relative_path)`, a read-only counterpart to
`local_save`/`local_read` for data supplied by someone else (e.g. NHC) rather
than generated by this project. It fetches a file from the project's new
`SOURCE_MATERIAL_DIR` (set in `tdrive_sync_config.py`, alongside `BASE_DIR`/
`DATA_VERSION`) and caches it locally, with no `DATA_VERSION`, no save side,
and no interaction with `TTDRIVE_SYNC_LOCAL_MODE`.
