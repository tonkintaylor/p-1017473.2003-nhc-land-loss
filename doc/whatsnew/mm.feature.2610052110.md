`gen_hazard.main` (and so `gen_all.py`) now runs landslide step 12's faces, wall units and per-world wall zones. Step 12's `WORLD_IDS` is read from exposure rw step 6's config, so the world list is set in one place. The faces script keeps the found elements (`urban-slope-found.pkl`), and `gen_urban_slope_wall_zones.py` builds from them rather than running the pip to element pipeline a second time. Landslide step 8 now stops with an error when no drawn wall names a polygon edge line, the case since rw step 6 draws wall units, rather than build every polygon `no_wall`.
