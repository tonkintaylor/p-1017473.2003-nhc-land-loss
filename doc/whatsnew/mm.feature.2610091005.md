Ground step 3 (instability zones) now runs a tiled extent's tiles in parallel, `TILE_WORKERS` (4) at once, and keeps each tile on disk as it is done. A run that stops partway resumes from the tiles not yet done. Kept tiles are reused only by a run with the same settings, DEM, ground map and search code; any other run, or `REBUILD`, clears them first. The siz table's grid columns and the element polygons moved to `grid.py` beside the step.
