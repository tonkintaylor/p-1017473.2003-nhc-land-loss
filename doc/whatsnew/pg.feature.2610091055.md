The loss viewer types each claim as liquefaction only, retaining wall only, landslide only, or a combination, in place of liquefaction only, retaining wall only and both, so landslide ground with no wall on it is no longer shown as a retaining wall claim. The viewer CSV carries `has_landslide` for this, and the map's true or false colourings are labelled True and False rather than 1 and 0.
