Landslide step 4 does about a third of the work per tile over a tiled extent, with the same zones: a tile draws only the polygons of the elements it owns, draws a polygon's outline once for every scenario that gives it the same cells (`polygon_geometries` takes an optional `cache`), and shares the rays set out from the crest cells between its scenarios (`build_slope_polygons` takes an optional `shared`). On the Porirua pilot in four tiles one worker takes 46 s rather than 144 s.
