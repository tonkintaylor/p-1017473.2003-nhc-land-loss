Landslide step 4 builds the wall zones of a tiled extent on several worker processes (`TILE_WORKERS` in its `config.py`), keeps each tile's zones on disk as it is built and resumes a stopped run from the tiles not yet built, as ground step 3 does. The kept tiles are cleared and built again when the found elements, the wall units or draws, the scenarios or the code that builds a tile change, or when `REBUILD` is set. The tiles are stitched in tile order, so the zones equal a one-process run's. The tile builder and the zone functions it uses moved to `zone_tiles.py` so that a worker can import them.
