A QGIS project now steps through the liquefaction land damage pipeline: the lateral spreading free faces and zones, the probability of each land damage state, the state drawn per grid cell, the point each property samples it at, and each property's state, evacuated area and inundated share (T-71). `gen_liq_pipeline_qgis_project.py` writes the project and every file it reads to the liquefaction module's folder, `hazard/liquefaction/` under `QGIS_DIR` in its `config.py` (`U:\MAMI\land-loss`), so the team can open it; it is run by hand. It sits in a new `src/scripts/landloss/post_processing/qgis_projects/` folder, which holds scripts that look over the outputs but are not published in the technical report.
