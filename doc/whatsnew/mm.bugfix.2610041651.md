The NZ Active Faults Database reader now takes `NZAFD_AF250.geojson` through `tdrive_sync.get_cached`, from the local copy in `.tdrivecache`, and `landloss.io.gfdb` reads the Ground Failure Database geodatabase from its copy under `.tdrivecache/DataLibrary/130.10_ground_failure_inventory_INT_Schmitt2022/` when one is there, falling back to `R:`. `tdrive_sync` cannot mirror a geodatabase folder, so to share the GFDB copy that folder is copied in by hand, keeping its `v1/data` layout. The GFDB event reader also filters with `LIKE` and compares exactly in pandas, because an exact `event_name =` filter fails in GDAL 3.12's attribute-index code on this geodatabase.
