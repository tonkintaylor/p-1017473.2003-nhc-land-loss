The loss viewer and calculation walkthrough scripts (`gen_calc_walkthrough.py`, `gen_viewer_data.py`, `gen_viewer_stress_data.py` and `loss_viewer.html`) have moved from `src/scripts/landloss/loss/validations/` to a new `src/scripts/landloss/loss/ui/` folder, since they are views onto the loss inputs and outputs rather than checks on them (T-85). Run them from the new paths, for example `uv run --frozen python src/scripts/landloss/loss/ui/gen_viewer_data.py`. Their output folders are unchanged.
