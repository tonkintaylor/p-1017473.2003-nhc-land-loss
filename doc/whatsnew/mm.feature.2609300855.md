Added `landloss.io.gfdb`, a reader for the USGS Ground Failure Database (GFDB
v4) -- a global compilation of earthquake-triggered landslide and liquefaction
inventories, 1905-2021. The dataset is catalogued as
`130.10_ground_failure_inventory_INT_Schmitt2022` in the cross-project
`R:\DataLibrary`, unzipped there as delivered.
