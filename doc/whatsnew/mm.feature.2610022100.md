Model builds now run over a named extent (`EXTENT = "wlg-pilot"` or `"full"`) instead of a `PILOT` flag, so builds over different extents no longer overwrite each other. The extents live in `landloss.io.area_of_interest.EXTENTS`. Existing pilot and full outputs keep their file names. Slope failure susceptibility outputs over the Johnsonville and Newlands box are now suffixed `-wlg-earthworks-pilot`.
