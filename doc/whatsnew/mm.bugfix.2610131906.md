The exposure pipeline (`gen_exposure.py`) now runs exposure rw step 8, the wall age by property (`gen_rwt_age.py`) and by suburb (`table_rwt_age_by_suburb.py`), over the run's extent before "rw s6, wall age", and the age shares read that run. Before, step 8 had to be run by hand and the age shares read `AGE_EXTENT` (Wellington City), so a run over another extent such as Lower Hutt stopped at the wall age step. `AGE_EXTENT` is now read only when `gen_wall_age.py` is run on its own.
