Two scripts archive a finished run to T:. archive_results.py copies each territorial authority's results from the run that built it into the versioned data store, where tdrive_sync would have saved them (versioned_data/v1/<module>/...), with the loss viewer and equity figures under report/, leaving out the DEMs and grids derived from them, the tile caches and the QV roll's per-property records. archive_web_inputs.py copies the newest cached version of each Koordinates layer and table, the WCC ArcGIS and GNS WFS extracts and the LINZ elevation catalogue JSON to SourceMaterial/web-downloaded-inputs, with a manifest of versions and hashes and, in place of the DEMs, a record of the LiDAR surveys and each DEM's hash. Both only plan by default, never overwrite, and copy with --copy.
