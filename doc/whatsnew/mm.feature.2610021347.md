Read the NZMM address land attributes extract for the four Wellington councils with `landloss.io.nzmm_land_attributes.get_nzmm_land_attributes`: one row per address with its property's land area, retaining wall flag, mean slope class and swimming pool flag, columns snake_cased, the Y/N flags as booleans, and exact repeat rows dropped. The file sits under `SourceMaterial/SENSITIVE` on T: (`NZMM_LAND_ATTRIBUTES_SOURCE_PATH`) and is to be destroyed, with its local cache copy, at the end of the project.
