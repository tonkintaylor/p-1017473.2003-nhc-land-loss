The QV land value is now taken as already including GST, so it is no longer grossed up by 15% before the land cover cap is compared with the GST-inclusive repair cost; the comparison stays like for like. The loss viewer works before GST and still divides the land rate by 1.15, which now removes the GST the QV value is taken to include. The land value method note, the loss status file, the QV figure labels, the equity figure notes and Appendices C and D say so.
